# Feature Specification: Movie Watchlist

**Feature Branch**: `team-5`

**Created**: 2026-09-20

**Status**: Draft

**Input**: User description: "สร้างเว็บสำหรับเก็บหนังหรือซีรีส์ที่อยากดู เพิ่มชื่อเรื่อง แนวหนัง และปีที่ฉาย ค้นหา กรองสถานะ ดูจบ ให้คะแนน แก้ไข ลบ และเก็บข้อมูลไว้เมื่อกลับมาใช้งานอีกครั้ง"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - บันทึกและติดตามรายการที่อยากดู (Priority: P1)

ผู้ใช้เพิ่มหนังหรือซีรีส์ลงในรายการ เห็นรายการล่าสุดอยู่บนสุด และเปลี่ยนสถานะของแต่ละเรื่องระหว่างยังไม่ได้ดูกับดูจบแล้ว เพื่อใช้ติดตามสิ่งที่สนใจได้

**Why this priority**: เป็นคุณค่าหลักของแอป หากไม่มีการเพิ่มและติดตามสถานะ ผู้ใช้ไม่สามารถใช้เป็น watchlist ได้

**Independent Test**: เพิ่มสองเรื่อง เปลี่ยนสถานะของหนึ่งเรื่อง แล้วรีเฟรชหน้า; ทั้งสองเรื่องยังอยู่ รายการล่าสุดอยู่บนสุด และสถานะถูกต้อง

**Acceptance Scenarios**:

1. **Given** ผู้ใช้ยังไม่มีรายการ **When** กรอกชื่อเรื่อง แนวหนัง และปีที่ฉาย แล้วเพิ่มรายการ **Then** ระบบแสดงการ์ดของเรื่องใหม่ในรายการ
2. **Given** มีหลายรายการ **When** เพิ่มรายการใหม่ **Then** การ์ดของรายการใหม่อยู่บนสุด
3. **Given** มีรายการที่ยังไม่ได้ดู **When** ผู้ใช้สลับสถานะเป็นดูจบแล้ว **Then** การ์ดแสดงสถานะที่แตกต่างอย่างชัดเจนและผู้ใช้สลับกลับได้
4. **Given** มีรายการอยู่แล้ว **When** ผู้ใช้รีเฟรชหรือกลับมาเปิดแอปอีกครั้ง **Then** ข้อมูลรายการและสถานะเดิมยังคงอยู่
5. **Given** ช่องชื่อเรื่องว่าง **When** ผู้ใช้พยายามเพิ่มรายการ **Then** ระบบไม่เพิ่มรายการและแจ้งให้กรอกชื่อเรื่อง

---

### User Story 2 - ค้นหาและดูรายการตามสถานะ (Priority: P2)

ผู้ใช้ค้นหาชื่อเรื่องขณะพิมพ์และเลือกดูทั้งหมด เฉพาะเรื่องที่ยังไม่ได้ดู หรือเฉพาะเรื่องที่ดูจบแล้ว พร้อมเห็นจำนวนเรื่องที่ดูจบและจำนวนเรื่องที่เหลือ

**Why this priority**: ช่วยให้ watchlist ที่มีหลายรายการค้นหาและติดตามความคืบหน้าได้สะดวก

**Independent Test**: เพิ่มเรื่องที่มีสถานะต่างกัน ค้นหาชื่อส่วนหนึ่ง และสลับตัวกรองทั้งสามแบบ; รายการที่เห็นและตัวเลขสรุปต้องตรงกับข้อมูล

**Acceptance Scenarios**:

1. **Given** มีรายการหลายเรื่อง **When** ผู้ใช้พิมพ์คำค้นที่ตรงกับส่วนหนึ่งของชื่อเรื่อง **Then** ระบบแสดงเฉพาะเรื่องที่ชื่อตรงกับคำค้นทันที
2. **Given** มีเรื่องทั้งที่ดูจบและยังไม่ได้ดู **When** ผู้ใช้เลือกตัวกรองสถานะ **Then** ระบบแสดงเฉพาะรายการของสถานะนั้น
3. **Given** มีรายการใน watchlist **When** สถานะหรือจำนวนรายการเปลี่ยน **Then** ระบบอัปเดตจำนวนเรื่องที่ดูจบและจำนวนเรื่องที่เหลือทันที
4. **Given** คำค้นไม่ตรงกับชื่อเรื่องใด **When** ระบบกรองผลการค้นหา **Then** ระบบแสดงข้อความว่าไม่พบเรื่องที่ค้นหา

---

### User Story 3 - ปรับข้อมูลและบันทึกความชอบ (Priority: P3)

ผู้ใช้แก้ไขชื่อเรื่องและแนวหนังของรายการเดิม และให้คะแนนความชอบ 1 ถึง 5 ดาวได้หลังดูจบ เพื่อให้รายการสะท้อนข้อมูลและความเห็นปัจจุบัน

**Why this priority**: เพิ่มประโยชน์หลังเริ่มใช้ watchlist โดยไม่กระทบการบันทึกและค้นหารายการพื้นฐาน

**Independent Test**: เพิ่มเรื่อง เปลี่ยนเป็นดูจบ แก้ไขชื่อและแนวหนัง แล้วให้คะแนน 1 และ 5 ดาว; ข้อมูลที่แสดงและคงอยู่หลังรีเฟรชต้องตรงกัน

**Acceptance Scenarios**:

1. **Given** มีรายการอยู่แล้ว **When** ผู้ใช้แก้ไขชื่อเรื่องและแนวหนัง **Then** การ์ดแสดงข้อมูลใหม่ของรายการนั้น
2. **Given** รายการมีสถานะดูจบแล้ว **When** ผู้ใช้เลือกคะแนน 1 ถึง 5 ดาว **Then** ระบบบันทึกและแสดงคะแนนที่เลือก
3. **Given** รายการยังไม่ได้ดู **When** ผู้ใช้เปิดการ์ดรายการนั้น **Then** ระบบไม่อนุญาตให้ตั้งคะแนนความชอบ
4. **Given** รายการที่ให้คะแนนแล้ว **When** ผู้ใช้รีเฟรชหรือกลับมาเปิดแอปอีกครั้ง **Then** คะแนนเดิมยังคงอยู่

---

### User Story 4 - ลบรายการที่ไม่ต้องการ (Priority: P4)

ผู้ใช้ลบรายการทีละเรื่อง หรือล้างเฉพาะรายการที่ดูจบทั้งหมด เพื่อคงให้ watchlist มีเฉพาะเรื่องที่ยังต้องติดตาม

**Why this priority**: เป็นการจัดระเบียบรายการหลังใช้ฟังก์ชันหลักได้แล้ว

**Independent Test**: เพิ่มรายการที่มีทั้งสองสถานะ ลบหนึ่งรายการ แล้วล้างรายการที่ดูจบ; รายการที่ยังไม่ได้ดูต้องไม่ถูกลบ

**Acceptance Scenarios**:

1. **Given** มีรายการอยู่แล้ว **When** ผู้ใช้เลือกลบรายการหนึ่งเรื่อง **Then** ระบบนำเฉพาะเรื่องนั้นออกจากรายการ
2. **Given** มีเรื่องที่ดูจบและยังไม่ได้ดู **When** ผู้ใช้เลือกล้างรายการที่ดูจบแล้ว **Then** ระบบลบเฉพาะเรื่องที่ดูจบและคงเรื่องที่ยังไม่ได้ดูไว้

### Edge Cases

- หากยังไม่มีรายการ ระบบแสดงข้อความต้อนรับให้เพิ่มเรื่องแรก
- หากคำค้นไม่ตรงกับรายการใด ระบบแสดงข้อความไม่พบเรื่องที่ค้นหา โดยไม่ลบข้อมูลจริง
- ชื่อเรื่องยาวต้องแสดงหลายบรรทัดได้และไม่ล้นออกจากการ์ด
- หากยังไม่มีเรื่องที่ดูจบ การล้างรายการที่ดูจบแล้วต้องไม่ลบเรื่องที่ยังไม่ได้ดูหรือทำให้เกิดข้อผิดพลาด
- คะแนนต้องรับได้เฉพาะค่าจำนวนเต็ม 1 ถึง 5 และตั้งได้เฉพาะรายการที่ดูจบแล้ว

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: ระบบ MUST ให้ผู้ใช้เพิ่มรายการหนังหรือซีรีส์ที่ประกอบด้วยชื่อเรื่อง แนวหนัง และปีที่ฉายได้
- **FR-002**: ระบบ MUST ไม่เพิ่มรายการเมื่อชื่อเรื่องว่าง และ MUST แสดงข้อความแจ้งข้อผิดพลาดที่เข้าใจได้
- **FR-003**: ระบบ MUST แสดงรายการเป็นการ์ด โดยเรียงรายการที่เพิ่มล่าสุดไว้ก่อน
- **FR-004**: ผู้ใช้ MUST สามารถสลับสถานะของแต่ละรายการระหว่างยังไม่ได้ดูและดูจบแล้วได้
- **FR-005**: ระบบ MUST แสดงรายการที่ดูจบแล้วให้แตกต่างจากรายการที่ยังไม่ได้ดูอย่างชัดเจน
- **FR-006**: ระบบ MUST ให้ผู้ใช้ค้นหารายการตามชื่อเรื่องได้ทันทีขณะกรอกคำค้น
- **FR-007**: ระบบ MUST ให้ผู้ใช้กรองรายการตามมุมมองทั้งหมด ยังไม่ได้ดู และดูจบแล้วได้
- **FR-008**: ระบบ MUST แสดงจำนวนเรื่องที่ดูจบและจำนวนเรื่องที่เหลือ และอัปเดตเมื่อข้อมูลเปลี่ยน
- **FR-009**: ผู้ใช้ MUST สามารถแก้ไขชื่อเรื่องและแนวหนังของรายการที่มีอยู่แล้วได้
- **FR-010**: ระบบ MUST ให้ผู้ใช้ให้คะแนนความชอบเป็นจำนวนเต็ม 1 ถึง 5 ดาวได้เฉพาะรายการที่ดูจบแล้ว
- **FR-011**: ผู้ใช้ MUST สามารถลบรายการทีละเรื่องได้
- **FR-012**: ระบบ MUST ให้ผู้ใช้ล้างเฉพาะรายการที่ดูจบแล้วได้ โดยไม่ลบรายการที่ยังไม่ได้ดู
- **FR-013**: ระบบ MUST รักษารายการ สถานะ และคะแนนของผู้ใช้ไว้เมื่อผู้ใช้รีเฟรชหรือกลับมาเปิดแอปอีกครั้ง
- **FR-014**: ระบบ MUST แสดง empty state ที่เหมาะสมเมื่อไม่มีรายการ และแสดง no-results state เมื่อผลค้นหาว่าง
- **FR-015**: ระบบ MUST แสดงการ์ดหลายคอลัมน์บนหน้าจอขนาดใหญ่และหนึ่งคอลัมน์บนหน้าจอขนาดเล็ก

### Key Entities

- **Movie**: รายการหนังหรือซีรีส์หนึ่งเรื่อง ประกอบด้วยชื่อเรื่อง แนวหนัง ปีที่ฉาย สถานะการดู คะแนนความชอบ (ถ้ามี) และเวลาที่เพิ่ม เพื่อระบุลำดับรายการล่าสุด
- **Watch Status**: สถานะของ Movie ว่ายังไม่ได้ดูหรือดูจบแล้ว ซึ่งกำหนดว่าสามารถให้คะแนนได้หรือไม่
- **View State**: คำค้นและมุมมองตัวกรองที่ผู้ใช้กำลังเลือก ใช้กำหนดรายการที่แสดงโดยไม่เปลี่ยนข้อมูล Movie

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ผู้ใช้เพิ่มรายการใหม่ที่มีข้อมูลครบได้ภายใน 30 วินาที และเห็นรายการนั้นบนสุดทันที
- **SC-002**: ผู้ใช้ค้นหาหรือกรองรายการ 20 เรื่องเพื่อพบรายการที่ต้องการได้ภายใน 10 วินาที
- **SC-003**: สถานะการดู คะแนน และข้อมูลรายการที่บันทึกไว้ยังถูกต้องครบถ้วนหลังรีเฟรชหน้าอย่างน้อย 3 ครั้งติดต่อกัน
- **SC-004**: ผู้ใช้สามารถระบุได้อย่างถูกต้องว่าเรื่องใดดูจบแล้วจากหน้ารายการโดยไม่ต้องเปิดรายละเอียดเพิ่มเติม
- **SC-005**: ผู้ใช้บนหน้าจอเดสก์ท็อปและสมาร์ตโฟนสามารถอ่านชื่อเรื่องยาวและใช้งานฟังก์ชันหลักได้โดยไม่มีเนื้อหาล้นขอบ

## Assumptions

- แอปมีผู้ใช้งานภายในเบราว์เซอร์เดียว และไม่ต้องแชร์ข้อมูลระหว่างอุปกรณ์หรือบัญชี
- ชื่อเรื่องเป็นข้อมูลบังคับ; แนวหนังและปีที่ฉายจะแสดงเป็นข้อมูลประกอบตามค่าที่ผู้ใช้กรอก
- คะแนนก่อนหน้าของเรื่องที่กลับไปเป็นสถานะยังไม่ได้ดูจะไม่แสดงหรือแก้ไขได้ จนกว่าจะทำเครื่องหมายว่าเรื่องนั้นดูจบแล้วอีกครั้ง
- การแก้ไขครอบคลุมเฉพาะชื่อเรื่องและแนวหนังตามโจทย์ ไม่รวมปีที่ฉาย
- ไม่มีการค้นหาภายนอกหรือดึงข้อมูลภาพยนตร์อัตโนมัติ; ผู้ใช้เป็นผู้กรอกข้อมูลรายการเอง
